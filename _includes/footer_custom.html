{%- comment -%} Sequential prev/next pager for the journal. just-the-docs has no built-in prev/next, but footer_custom.html is an officially supported override that renders at the bottom of every page's main content -- which is exactly where a "finished reading, go to the next entry" control belongs. Ordering comes from each entry's nav_order, the same field driving the sidebar, so the reading order can never disagree with the nav. nav_order is an integer, so `sort` orders it numerically (as strings, "10" would sort before "2"). The dir filter scopes this to journal entries only, so index.md gets no pager. Files excluded in _config.yml never enter site.pages, so tokenizer_notes.md and workflow.md drop out for free. {%- endcomment -%} {%- assign entries = site.pages | where: "dir", "/journal/" | sort: "nav_order" -%} {%- assign here = -1 -%} {%- for e in entries -%} {%- if e.url == page.url -%}{%- assign here = forloop.index0 -%}{%- endif -%} {%- endfor -%} {%- if here >= 0 -%} {%- assign last = entries | size | minus: 1 -%}
{%- if here > 0 -%} {%- assign i = here | minus: 1 -%} {%- assign prev = entries[i] -%} ← Previous {{ prev.title }} {%- endif -%}
{%- if here < last -%} {%- assign j = here | plus: 1 -%} {%- assign next = entries[j] -%} Next → {{ next.title }} {%- else -%} Next → Back to the index {%- endif -%}
{%- endif -%}
